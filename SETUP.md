# YNJ05 GitHub Profile README

## Files

- `README.md` — the complete GitHub profile README.
- `assets/profile-banner.png` — the monochrome illustrated hero banner used at the top of the README.

## Install on GitHub

1. Open https://github.com/new while signed in as `YNJ05`.
2. Create a **public** repository named exactly `YNJ05` (same spelling and capitalization as your GitHub username).
3. Add `README.md` at the repository root.
4. Upload the `assets` folder with `profile-banner.png` inside it.
5. Commit the files to the repository's default branch.
6. Visit https://github.com/YNJ05 to see the profile README.

If the `YNJ05` repository already exists, replace its `README.md` and upload/replace `assets/profile-banner.png`; do not create a second repository.

## Personal details to verify

Before publishing, verify the email, LinkedIn, portfolio, certificate names, and project repository URLs in `README.md`. The badges and typing animation use external services (Shields.io, readme-typing-svg, and capsule-render). The banner itself is stored locally in this repository.

## Customize

- Change the banner by replacing `assets/profile-banner.png` while keeping the same path, or update its path in `README.md`.
- Edit the YAML block under `> whoami` to update your status and interests.
- Add/remove technology badges in the `> stack --list` section.
- Add projects to the table under `> ls projects/`.
